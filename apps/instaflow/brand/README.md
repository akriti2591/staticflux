# Instaflow brand: the mark

Chosen by the owner on 2026-10-25, round 4 of the logo exploration (canvas "Instaflow Logo"): the **cursive "if"**
with a **colour-split dot** and **no tail**. One stroke writes the i flowing into the f; the i's dot glitches into
StaticFlux's orbit colours, tangerine and mint, which ties Instaflow to the framework it is built on.

## Files
| File | Use |
|---|---|
| `instaflow-mark.svg` | The mark on light backgrounds (Clean Pop mist, white) |
| `instaflow-mark-on-dark.svg` | The mark on ink or dark backgrounds |
| `instaflow-mark-mono.svg` | One colour (ink; the split dots at 30 % opacity) for stamps, embossing, single-ink print |
| `favicon.svg` | Browser tab icon; switches to white strokes in dark mode |
| `favicon-16.png`, `favicon-32.png`, `favicon-48.png` | Favicon fallbacks |
| `instaflow-app-icon.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | App icon: the on-dark mark on an ink tile (rounded 112/512) for the web app manifest and home screens |
| `instaflow-mark-1024.png` | Large raster for slides, social posts and the README |

All marks are drawn on a 64 × 64 grid. Don't edit the geometry by hand; change it on the canvas and re-export.

## Colours (Clean Pop)
Ink `#16151A` (stroke and core dot) · tangerine `#FF5C39` (split, up-left) · mint `#00B37E` (split, down-right). On
dark: white stroke and core, the same tangerine and mint.

## Lockup
Mark + "Instaflow" in Bricolage Grotesque 800, letter-spacing −0.02 em, ink. Mark height = 1.45 × the wordmark's cap
height; gap between mark and word = 0.25 × mark height. Clear space around the lockup: half the mark height.

## Don't
Recolour the split dots, add a tail, outline the mark, put it on busy photos without a tile, or stretch it.
