## Decisions (why)
- Authoring split into 3 artifacts by cargo feature (geometry / text / text-complex) via new `sf wasm build` options
  `package`, `features`, `defaultFeatures` (tooling/sf/src/wasm-build.ts): geometry+text together = 389.7 KB > 350 budget.
- Render draws glyphs from skrifa glyf scaler + read-fonts CFF, not glifo/`OutlineGlyph::draw`: those link the hinter
  (346.6 / 299.3 KB). Trade-off: no COLR/CBDT colour emoji yet.
- Scene IR bumped to v3 on top of B1's v2; TS/Rust writers byte-identical; all fixtures regenerated.
- Paragraph styles are `p.*` marks on each paragraph's terminating `\n` (content always ends with `\n`).
- IME composition is a local preview; only `compose-commit` writes to the CRDT.
- Text kind = B1 `ELEMENT_COMMON_COMPONENTS` + `text`; match key = B1 `lineage.key`, default `lk_<node>`.
- Fonts keyed by sha-256 (blob digest); Loro peers must use `TEXT_MARK_EXPAND`.
