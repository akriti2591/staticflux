## Public API (full list in `packages/kit/AGENTS.md`)
- **Icons:** `import { trash2Icon } from '@staticflux/kit/icons/trash-2'` → `html\`<sf-icon .icon=${trash2Icon} size="18"></sf-icon>\``.
  `size` 16 (default; rows, menus, inspector, tags) · 18 (icon buttons, tool picker) · 24 (cards, empty states). Decorative
  unless `label` (then `role="img"`). Icons are typed values (rule 1), not names; `name` is only reflected. `defineIconElement()`.
  New icon: add the Lucide name to `icons/icons.json` (or an SVG to `icons/custom/`), run `node packages/kit/scripts/generate-icons.mjs`.
- **Number field:** `<sf-number-field label="W" unit="px" .units=${{ px: 1, in: 96 }} .value=${920} min="1" ?mixed=${m}
  wrap="angle" percent-of=…>`; listen to `sf-input` (live scrub preview) and `sf-change` (`{ value, delta, source }`, once
  per gesture). Mixed: `value` is undefined and `delta` is what to add to each. `parseNumberInput` is usable on its own.
- **Inline edit:** `<sf-inline-edit label="Layer name" .value=${name} maxlength="200" trigger="dblclick|click|none">`;
  call `edit()` from menus / `Mod+Shift+R` / Enter on a row; `sf-change` `{ value, previous }` only on a real change; `sf-cancel`.
- **Swatch:** `<sf-swatch color=${resolvedHex} .opacity=${0.8} ?unresolved=${!resolved}>` (decorative; say the value in text).
- **Instaflow:** `layerKindIcon(kind)`, `toolIcon(tool)`, `REPEAT_ICONS`, `BOOLEAN_ICONS` from `apps/instaflow/src/theme/icons.ts`.

## Decisions (and why)
- Icons are `IconDef` values, not `name` strings (rule 1, and only imported icons ship); spec's `<sf-icon name>` became `.icon`.
- Lucide **1.54.0** (dev dependency of the kit, so `licenses:check` sees it); 1.x renamed some icons — the generator resolves aliases
  (`trash-2` → current `trash` geometry) and keeps the spec's names.
- Number field: a leading `-` is a negative number, not "subtract" (Figma); `+ * /` are relative. Inline edit: a refused **blur** restores
  the old name (focus is already gone), a refused **Enter** keeps editing with the error.
- Kit strings stay American ("color") like the rest of the kit; Instaflow translates through `kitMessages` if wanted.
