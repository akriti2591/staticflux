## Decisions (and why)
- **PDF on `pdf-writer`, not krilla** (M1-PLAN said krilla): krilla measured 481 KB brotli in the export Wasm, over the
  400 KB export-extras budget. Text = Type 3 from the canvas's own outlines + ToUnicode + ActualText (extractable).
- SVG keeps shadows and blurs as filters; PDF patches them (2 px per design px); conic gradients are pixel patterns.
- PDF is scored at 2× (at 1× poppler's stroke adjustment and image sampling dominate: images 0.968).
- GPU test 2×/3× vs 1× bar = blurred SSIM ≥ 0.98 + no missing content (Vello's conflation seam: masks 3× = 0.984).
- Export fixtures are `src/export/testing/test-helpers.ts` (the build excludes test helpers; it failed with TS6307).
- Package exports `./export` (main side only) and `./export/panel`; the job/scene/snapshot stay worker-only.
- Budgets raised by IR v4 (glyph runs carry text): `@instaflow/app/render` 3.9 → 4.15 KB, `library` 10 → 10.25 KB.
