## Decisions (and why)
- **PDF on `pdf-writer`, not krilla** (M1-PLAN said krilla): krilla in the export Wasm measured 481 KB brotli, over
  the 400 KB IF-15.1 budget. Text is Type 3 from the canvas's own outlines with ToUnicode and ActualText (extractable).
- Rasterize list (D21): shadows and blurs → raster patches (2 px per design px); conic gradients → pixel patterns.
- Export fixtures renamed to `src/export/testing/test-helpers.ts`: the build excludes `test-helpers.ts`, and the
  fixtures import other test helpers (the build failed with TS6307 before).
