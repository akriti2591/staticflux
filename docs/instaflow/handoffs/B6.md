## Decisions (and why)
- Reused `@staticflux/surface`'s accessible layer instead of a new DOM reconciler; added generic options (R11.60–R11.62:
  role description, level, roving `tabIndex`, `activateKeys: []`, visible `focusRing`). `activateKeys: []` is essential:
  the layer used to swallow Enter/Space before B3's shortcuts (the registry skips `defaultPrevented` events).
- Roles limited to `group`, `img`, `heading` (name allowed, roving tabindex allowed); state goes into the role
  description and `aria-description` (`aria-selected` is invalid on those roles). The canvas surface stays Studio's
  `role="application"`, so B3's arrow keys reach the app with a screen reader on.
- Plain groups are never taken from B3's index: their indexed bounds go stale when a child is created or moves (B3 only
  re-indexes the dirty subtree, not ancestors). A group is in view when a descendant is.
- Stage fix (`packages/stage`): `onInvalidate` now also names root-document nodes nothing has read yet (created since).
  Without it neither B3's index nor the projection ever saw newly created elements (R11.8n text amended, no new ID).
- Audit = the repo's `@staticflux/testkit/a11y` (no axe dependency), extended generically (R15.6).
