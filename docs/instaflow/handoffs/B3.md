## Decisions and why
- Drag previews go to the stage's session layer (strongest, never persisted, drawn through the render projection). On
  release, one B1 `commitEdit` runs, so each drag is one undo step and passes lock and brand checks for free.
- Gesture kind comes from tables (`PRESS_GESTURES`, `GESTURES`, `TOOL_BEHAVIOURS`, `ARROW_ACTIONS`), never a mode `if`
  (repo rule 4).
- Frames are transparent and groups opaque for click targets (Figma-like). Fully locked elements (position + content)
  can't be selected on the canvas; position-locked ones can be selected but never move.
- Paint order is computed per candidate (child-index path), not kept as a global order.
- Snapping stability is guaranteed by strict nearest choice (ties keep the first; an exact match always wins).
- Shortcut scope `instaflow/canvas-tools` declares its parent as a scope with id `instaflow/studio`, so it doesn't
  import `studio.ts` (the registry compares scopes by id).
- Select and Hand reuse B0's ids `instaflow/select` and `instaflow/hand`.
