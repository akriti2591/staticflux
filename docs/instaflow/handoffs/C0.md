## Decisions (and why)
- **Home and Studio are separate pages** (separate boots), routes `/`, `/s/:asset`, `/new?format|template` as
  `@staticflux/router` route values (table only, no navigation pipeline). The dev server maps them to the two HTML pages.
- **Home reads a projection, not the library doc** (the library is a Loro document): `head.app.home`, CAS-written by the store
  side on library changes and on writes of a design's document (`observeStoreWrites`), debounced; flushed before leaving Studio.
- **Persistent store = IndexedDB via `@staticflux/storage`**, not the OPFS journal: the B5 "blob ↔ DocumentStore adapter"
  follow-up stays open; the IDB adapter is per-tab serialized + Web Locks across tabs.
- New designs are listed in the library **after** the editor opened them; the title is "Untitled design" (no rename UI yet).
- M1 quick actions = one per design format (post, story, carousel, slides, poster). The design's agent-backed quick actions
  (remove background, captions, …) arrive as rows with their own capabilities in M2. The hero composer arrives with Chat (M2).
- Thumbnails are format-shaped placeholders (page thumbnails are a B4 follow-up).
- Studio smoke: `undoDepth` now flushes Latest first (`StudioApp.flush()`); undo depth counts *durable* commits and
  IndexedDB durability trails an edit by milliseconds (the B10a numeric-bar check raced once without it).
- `@staticflux/kit (full)` budget 22.5 → 22.6 KB (the card; reason in the entry name).
