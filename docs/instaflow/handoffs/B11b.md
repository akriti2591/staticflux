## Slice 1 — what landed
- Canvas model: the canvas clears transparent (premultiplied alpha surface, `STUDIO_BACKGROUND`), so the CSS room shows
  through: mist dot grid, page card with shadow, page label `Name · W × H` above it. Frames get a 1 px hairline overlay
  (`FRAME_OUTLINE_FIRST_ID`), re-sent only when zoom or frame geometry changes.
- Top bar: inline SVG logo mark (`theme/logo.ts`), title rename (inline edit, renames the library entry), M1 lenses
  (Canvas, Pages), saved / milestone popover (name + Create), View menu (zoom items, density radio), overflow (Save as
  template…, Rename…, Copy link), Export primary button opening the Export dialog (surface manager).
- Tool picker: Select, Shapes family (Rectangle, Ellipse, Polygon, Star, Line in one menu), Text, Hand, Lucide icons,
  tooltips with shortcuts; zoom pill with menu.
- HUD pill: `studio/hud.ts` on `spec/controls.ts` + `studio/studio-controls.ts`, one control set per selection kind
  (shape, text, image, frame, group, multi, mixed, locked, repeat, boolean, mask), ≤ 6 then More (filterable, grouped
  by `MORE_GROUPS`). Placed above the selection (below when no room), hidden during gestures, frozen while a popover
  is open.
- Scene mirror (`workers/mirrors.ts` `SceneMirror`, `app/scene-summary.ts`): layers tree, selection summary, page,
  frame AABB, document colours; actions setPaint / setProp / move / renamePage.
- Studio commands (`app/studio-commands.ts`): delete, duplicate, lock, undo, redo capabilities; key map
  `STUDIO_KEY_COMMANDS` (undo, redo, delete, duplicate, group, ungroup, frame selection, z-order ×4, lock, hide) run in
  the editor via the input ring, with chrome-scope fallbacks on main. Undo/redo serialized; selection pruned on undo.
- Toasts: milestone created, template saved, export done, "Deleted N elements" (undoable) for ≥ 5, link copied.
- Kit fix: `sf-menu-item` / `sf-icon-button` crashed on a `nothing` shortcut (null) — guarded, regression test.

- Rotate handle: visible, 24 px below the frame's bottom edge on a stem (`ROTATE_STEM_HANDLE`), plus the corner zones.
- Command bar (`studio/command-bar.ts`, §4.4): bottom-centre pill, `Mod+K` opens it on its filter; rows are the
  selection's applicable capabilities, undo / redo, tools and the camera; recent first (per browser); Enter runs the
  top row.
