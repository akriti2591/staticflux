## Slice 1 — what landed
- Canvas model: the canvas clears transparent (premultiplied alpha surface, `STUDIO_BACKGROUND`), so the CSS room shows
  through: mist dot grid, page card with shadow, page label `Name · W × H` above it (a button: click selects the page and
  opens Page in the inspector, double-click focuses its name). Frames get a 1 px hairline overlay (`FRAME_OUTLINE_FIRST_ID`).
- Top bar: inline SVG logo mark (`theme/logo.ts`), title rename (inline edit, renames the library entry), M1 lenses
  (Canvas, Pages), saved / milestone popover (name + Create), View menu (zoom items, density radio), overflow (Save as
  template…, Rename…, Copy link), Export primary button opening the Export dialog (surface manager).
- Tool picker: Select, Frame, Shapes family (Rectangle, Ellipse, Polygon, Star, Line in one menu), Text, Hand, Lucide icons,
  tooltips with shortcuts; zoom pill with menu.
- HUD pill: `studio/hud.ts` on `spec/controls.ts` + `studio/studio-controls.ts`, one control set per selection kind, ≤ 6 then
  More (filterable, grouped). Placed above the selection (below when no room), hidden during gestures, frozen while a popover
  is open. Fit now sets the image fill's fit (the old `image.fit` prop was never read by the renderer).
- Scene mirror (`workers/mirrors.ts` `SceneMirror`, `app/scene-summary.ts`): layers tree, selection summary (+ image fit,
  asset, crop; opacity, blend), page, page Background, page count, frame AABB, document colours; actions setPaint, setProp,
  move, renamePage, applyPage, resizePage, setImageFit. Protocol request `replaceImage`.
- Studio commands (`app/studio-commands.ts`): delete, duplicate, lock, undo, redo capabilities; key map
  `STUDIO_KEY_COMMANDS` run in the editor via the input ring, with chrome-scope fallbacks on main.
- Toasts: milestone created, template saved, export done, "Deleted N elements" (undoable) for ≥ 5, link copied.
- Visible rotate handle 24 px below the frame on a stem (`ROTATE_STEM_HANDLE`), plus the corner zones.
- Command bar (`studio/command-bar.ts`): bottom-centre pill, `Mod+K`, recent first, Enter runs the top row.
- Kit fix: `sf-menu-item` / `sf-icon-button` crashed on a `nothing` shortcut (null) — guarded, regression test.

## How to try
`pnpm build && pnpm --filter @instaflow/app dev`, open a design: with nothing selected the inspector shows Page (resize it,
change the Background); draw a rectangle, recolour it from the pill or the inspector, add a gradient fill (`+ Add ▾ ›
Gradient`), open Effects and add `Shadow › Soft`; type text and try Style ▾, Strikethrough, More ▾ › Superscript and Case;
Mod+K and type "dup"; Mod+A then Group (pill), Ungroup, Delete, Mod+Z. Export from the top bar.
