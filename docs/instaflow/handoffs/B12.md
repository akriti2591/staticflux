## Decisions (and why)
- `hidden` is `spatial.hidden` (additive field, like B10a's `skewX`): every element kind has `spatial`, locks don't cover it.
- The page fill is a projected record with id `<page>#fill` and order key `''`, not the page node itself (children would nest under
  a drawn node, and text groups are root siblings). Selection exports keep the old white background unless transparent.
- Crop is a new IR paint tag (6), so every existing scene and golden is byte-identical; offset is 0…1 of the free space.
- WOFF2 decoding is a lazy fourth Wasm artifact from the authoring crate (`webfont` feature, `wuff`): 77.2 KB brotli would push
  `authoring_text` (302 KB) towards its 350 KB budget. New budget category `authoring-webfont-wasm` 80 KB.
- Spec HUD limit 48 → 64 (`spec/schema.ts`): the registries test requires every HUD action to be placed.
- Ungroup of a mask group releases the mask (otherwise it would start masking the parent's later siblings).
- T-9: B8 had already taken control bounds from the committed block; B12 adds ignoring key intents during a composition and fixes a
  regression it caused itself (the host re-laid out the block mid-composition; caught by the Studio smoke).
