# @staticflux/devtools

Devtools on the telemetry fabric: boot waterfall, journeys, DI graph, lifecycle states, decision traces, store inspector, violations, verbosity controls.

Part of **[StaticFlux](https://akriti2591.github.io/staticflux/)** — composable building blocks for client-side apps on the modern web.

```sh
pnpm add @staticflux/devtools
```

- API, rules and budgets: [AGENTS.md](./AGENTS.md)
- Docs: https://akriti2591.github.io/staticflux/
- Source: https://github.com/akriti2591/staticflux/tree/main/packages/devtools

All `@staticflux/*` packages are released together with the same version; use matching versions in one app.
