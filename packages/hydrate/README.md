# @staticflux/hydrate

Hydration: islands over prerendered HTML (visible/idle/interaction) and store-snapshot rehydration for instant boot.

Part of **[StaticFlux](https://akriti2591.github.io/staticflux/)** — composable building blocks for client-side apps on the modern web.

```sh
pnpm add @staticflux/hydrate
```

- API, rules and budgets: [AGENTS.md](./AGENTS.md)
- Docs: https://akriti2591.github.io/staticflux/
- Source: https://github.com/akriti2591/staticflux/tree/main/packages/hydrate
