# @staticflux/i18n — AGENTS.md

**Layer:** vertical (depends only on `@staticflux/core`).
**Budget:** full surface ≤ 7 KB brotli (measured 6.8 KB minified, core external); typical runtime import (service + messages + unit, no `check.ts`) ≤ 6 KB (measured 5.6 KB). Each locale catalog per feature ≤ 10 KB (R12.7). Not in the boot path unless a critical unit needs it.

## Purpose
Typed message catalogs per package, a small ICU MessageFormat subset, lazy locale
catalogs via injected loaders, locale negotiation + fallback chain, reactive
runtime locale switch, RTL/`dir` detection, `Intl` formatting helpers, and a
catalog check for CI (REQUIREMENTS §14, R14.1–R14.6).

## Public API (by file)
- `messages.ts` — `defineMessages(namespace, { key: 'ICU text' }, { sourceLocale })` → typed `MessageRef`s
  (params inferred from the ICU literal: `ParamsOf<S>`), `catalogOf`, `CATALOG`,
  `defineTranslations(messages, locale, {...})` (keys checked), `catalogLoader(messages, { fr: () => import(...) })`, `CatalogLoader`.
- `icu.ts` — `parseMessage` (Result; `SF-I18N-001`), `formatNodes`, `collectArgs`. Supported: `{x}`, `{x, number[, integer|percent|compact|::currency/EUR]}`,
  `{x, date|time[, short|medium|long|full]}`, `{x, list[, or|unit]}`, `{x, plural|selectordinal, [offset:n] =n {…} one {…} other {…}}` with `#`, `{x, select, … other {…}}`, ICU apostrophe quoting.
- `formatters.ts` — `createFormatters(locale, intl?)`: cached `Intl` number/currency/date/relative/list/plural with fallbacks when APIs are missing.
- `locale.ts` — `canonicalizeLocale`, `baseLocale`, `languageOf`, `localeFallbackChain`, `negotiateLocale`, `textDirection`.
- `service.ts` — `createI18n(options)` → `I18n` (`locale`/`dir`/`fallbackChain` reactive, `t`, `tryFormat`, `has`, `load`, `setLocale`, Intl helpers, `onChange`, `onIssue`, `inspect`);
  machines `LocaleMachine` (`i18n/locale`: ready ⇄ switching) and `CatalogMachine` (`i18n/catalog`: unloaded → loading → loaded | failed → loading); `I18nMetrics`.
- `check.ts` — `checkCatalogs({ catalogs, translations, locales?, usedIds? })`: missing / unused / unknown keys, placeholder mismatches, syntax errors.
- `units.ts` — tokens `I18nToken`, `I18nConfigToken`, `CatalogLoadersToken` (multi); `i18nUnit`, `i18nConfigUnit(config)`, `catalogLoaderUnit(loader)`; `bindDocumentLocale(i18n, el?, scope?)`.
- `errors.ts` — `SF-I18N-001` syntax, `-002` missing param, `-003` catalog load failed, `-004` malformed locale tag.

## Rules
- Never format with string keys: call sites use refs (`i18n.t(m.saved)`).
- `t()` never throws; problems go to telemetry (`i18n/locale`) and `onIssue`. Use `tryFormat` when you need the error.
- A locale switch flips only after every in-use catalog loaded for the new chain; failure keeps the old locale.
- A failed catalog never fails the app: source text is shown (degraded) and reported.
- Each locale of each catalog is its own lazy chunk (`catalogLoader` with dynamic imports); only the active locale may block (`config.preload`).
- Type-level param inference does not understand quoted braces (`'{'`); `checkCatalogs` does.
- Lifecycle machines above must stay mirrored in `docs/LIFECYCLES.md`.
