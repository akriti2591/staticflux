# @staticflux/advisors — AGENTS.md

**Layer:** vertical (depends only on `@staticflux/core`). Must not import `@staticflux/ai`, data or platform — models, storage and environment facts arrive through ports.
**Budget (proposed):** ≤ 5 KB brotli minified (service + decision + statistical + units). Not on the boot critical path except `decide()` for sync points.

> ## ⚠ ADVISORS ARE NEVER USED FOR AUTHORIZATION (R19.9)
> Advisors change performance, never correctness. `AdvisoryPurpose` is a closed set
> (`warmup | retention | scheduling | prefetch | messaging-timing | sampling`) and there is
> no API to ask an advisor about access, entitlements or security. Do not add one.

## Purpose
Framework decision points consult pluggable advisors through one typed contract
(R19.5–R19.14): typed question + closed option set → probability distribution. Advisors suggest; the
framework decides (clamp, time box, default).

## Public API (by file)
- `decision.ts` — `defineDecisionPoint({ id, purpose, options, latency: sync|idle|background, heuristic, constrain?, cacheKey?, budgetMs?, minConfidence? })`, `normalize`, `argmax`, `clamp`, `heuristicDistribution`, `stableKey`, `DEFAULT_BUDGET_MS` (1 / 50 / 500 ms).
- `advisor.ts` — `Advisor` contract (`id`, `tier: heuristic|statistical|model|remote`, `latency`, `supports`, `advise`), `advisorFor(point, …)` typed single-point authoring, `TIER_RANK`.
- `statistical.ts` — `AdvisorStoragePort` (structural subset of `@staticflux/storage` `AsyncStore`: async `get/set/delete`), `createMemoryAdvisorStorage`, `createMarkovModel` (bounded first-order Markov, decay, coalesced persistence, corrupt → reset SF-ADV-005), `createMarkovAdvisor` (sync, statistical; min observations → SF-ADV-003).
- `model.ts` — `DecisionModelPort` (satisfied structurally by `@staticflux/ai` providers' `decide`), `createModelAdvisor` + `modelBinding(point, encode)`; `RemoteAdvisorTransport`, `createRemoteAdvisor` + `remoteBinding(point, features)` (only the declared feature vector leaves the device, R19.14), `createMockRemoteTransport`.
- `service.ts` — `createAdvisorService({ advisors, environment, telemetry, idle, now, cacheSize, retryAfterMs, traceLimit })` → `decide` (sync, never blocks), `ask` (time-boxed, never rejects), `recordOutcome`, `stats` (hit rate, wasted bytes), `traces`, `addAdvisor(advisor, scope)`, `invalidate`, `dispose`. `Advice`, `DecisionTrace`, `AdvisorMetrics`, `consultationMachine`.
- `units.ts` — tokens `AdvisorServiceToken`, `AdvisorsToken` (multi), `AdvisorEnvironmentToken`, `AdvisorStorageToken`; `advisorUnits` (one-line opt-in), `advisorContribution`, `markovAdvisorUnits({ id, point, modelToken, storageKey, from })`, `browserAdvisorEnvironment` (navigator hints; Safari/Firefox → not downgraded).
- `errors.ts` — `SF-ADV-001` … `SF-ADV-006`.

## Semantics
- Sync points: only `latency: 'sync'` advisors are consulted, synchronously; a promise-returning advisor is skipped.
- Idle/background points: `decide()` returns cache or default (`fallback: 'pending'`) and starts one single-flight consultation; `ask()` waits up to `budgetMs` (idle: after one idle slot). Answers are cached per `point × environment × cacheKey(question)`; failures are negatively cached for `retryAfterMs`.
- Tier order: remote > model > statistical > heuristic; failures, invalid distributions and low confidence fall through; the time box is shared.
- Downgrade (low-end, save-data, battery saver, slow network) → heuristic + statistical only. Remote only with `allowRemote: true`.
- Clamping (point `constrain` ∧ call `constrain`) is applied at read time; an answer clamped to nothing falls back (`'clamped'`); `choice` is `undefined` when nothing is allowed.

## Lifecycle (mirror into docs/LIFECYCLES.md §14)
`advisors/consultation`: pending → (waiting-idle) → consulting → answered | defaulted; pending | waiting-idle | consulting → cancelled.

## Rules
- Never await `ask()` on a frame or navigation critical path; use `decide()` there.
- Advisors must be pure suggestion: no side effects, no network unless tier `remote`.
- Remote/model encoders send minimized, declared data only — never raw user content.
